# Tooth Hero

**Tooth Hero** is an Android-based educational game developed using Flutter and Dart. The game is designed to introduce elementary school students, particularly Grade 4 students, to dental health and proper oral hygiene through an interactive and engaging gaming experience.

Players explore five different levels, each forming part of the game's educational journey about maintaining healthy teeth.

## Game Overview

- **Game Name:** Tooth Hero
- **Genre:** Educational Game
- **Target Audience:** Elementary School Students (Grade 3-5)
- **Platform:** Android
- **Framework:** Flutter
- **Programming Language:** Dart
- **Number of Levels:** 5

## Features

- **Five Playable Levels** — Explore the game's five-level progression.
- **Educational Gameplay** — Learn about dental health through interactive activities.
- **Interactive User Interface** — Navigate the game's menus and level selection.
- **Game Instructions** — Access guidance on how to play.
- **Settings Menu** — Access available game settings.
- **Multimedia Elements** — Uses visual assets, audio, and video to support the gaming experience.

## Game Levels

Tooth Hero consists of five levels:

1. **Level 1** — The first stage of the player's journey.
2. **Level 2** — Continue exploring the educational game.
3. **Level 3** — Progress through the next stage.
4. **Level 4** — Continue the journey toward the final level.
5. **Level 5** — Reach the final stage of the game.

Each level is part of the overall Tooth Hero experience. Specific challenges and educational materials depend on the content implemented in each stage.
